# CPU 饱和处置手册

**适用症状**：CPU 持续高位、load 超过核数、请求 p99 上升

**常见成因**：热点计算、正则回溯、GC 抖动、流量突增

**处置步骤**：

1. 用 top -H 找到线程，再看是否集中在少数线程（热点计算）还是均匀分布（流量）
2. 采 30 秒火焰图，确认是业务代码还是 GC/序列化开销
3. 流量型：先扩容或限流保响应，再优化
4. 计算型：给正则与外部调用加超时，避免单请求拖垮工作线程
5. 确认是否有重试放大（无退避的重试会把 CPU 打成雪崩）
6. 优化后对比同窗口的 p99 与 CPU，避免只看均值

**严重级**：P1
