# 内存压力处置手册

**适用症状**：内存水位持续 85% 以上、swap 使用上升、GC 变频繁

**常见成因**：缓存无上限、大结果集一次性加载、泄漏

**处置步骤**：

1. 确认是应用堆内存还是页缓存：页缓存高但可回收不算问题
2. 给本地缓存加容量上限与淘汰策略（无上限的缓存是定时炸弹）
3. 检查是否有全表扫描式加载，改为分页或流式
4. 观察 GC 日志：老年代持续增长说明泄漏嫌疑大
5. 设置内存告警在 80%，而不是等到 OOM 才被发现

**严重级**：P1
